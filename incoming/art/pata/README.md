# incoming/art/pata — drop zone for the Painted cloth (Sanjaya's Pata) art

Drop files here with the exact names from `docs/prompts/PATA.md` (keep the sub-folder:
`pieces/`, `fields/`, `frame/`, `scenes/`, `portraits/`, `astras/`). The Director checks each one,
makes the small fast copy in `assets/art/pata/`, wires it in, and then moves the big original out
of the repository into the masters archive (`docs/MASTERS.md`). **This folder is empty when
everything is done** — an empty folder means nothing is waiting, not that art is missing.

Rules: transparent PNG (or flat magenta `#FF00FF`), never black · no text · no deity ·
one figure filling about 80 % of the frame · **no watermark** (check the bottom-right corner).
