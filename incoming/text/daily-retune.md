## Files and reproduction

`daily-retune-proposals.json` contains the eight revised draft objects. `daily-retune-bank3-inputs.json` contains the exact sixteen objects supplied to the unchanged simulator, including original controls. `daily-balance-bank3.json` is its unmodified output. The protocol includes base commit, source hashes, input hash, seed plan, and exact effective knob differences.

Run from the repository root in an isolated temporary directory so the original draft catalogue is preserved:

```bash
screen_dir=$(mktemp -d)
mkdir -p "$screen_dir/js" "$screen_dir/tools" "$screen_dir/incoming/text"
cp js/units.js js/geometry.js js/engine.js js/ai.js js/modes.js "$screen_dir/js/"
cp tools/simulate-daily.mjs "$screen_dir/tools/"
cp incoming/text/daily-retune-bank3-inputs.json "$screen_dir/incoming/text/daily-modifiers.json"
node "$screen_dir/tools/simulate-daily.mjs" 120 --seed=0x92d04b --output=incoming/text/daily-balance-bank3.json
cmp incoming/text/daily-balance-bank3.json "$screen_dir/incoming/text/daily-balance-bank3.json"
```
